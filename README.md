# EditLab Tracker for Claude

Make and edit songs with Claude in EditLab Tracker, a music app for the Mac. Claude reads the song you have open, writes and changes notes, picks sounds, arranges the sections, sets the mix and checks the result for clipping and clicks. Every change Claude makes is one step you can undo in Tracker, and you can change anything by hand.

## What you need

- A Mac with EditLab Tracker, free to download from the Mac App Store
- The Claude desktop app, with Tracker's Claude connector turned on: in Tracker, choose **Help > Use EditLab Tracker with Claude…**

## How to use it

Open a song in Tracker, or start a new one, and ask Claude. For example:

- "Make a two-minute lo-fi beat at 85 BPM with a mellow piano."
- "The chorus sounds muddy. Clean it up without changing the notes."
- "Take the drums out of the intro and add a build before the drop."
- "Undo what you just did to the hats."

Claude can't hear the song, so it plays it in Tracker and asks you how it sounds. Saving and exporting happen only when you ask, and exporting a song to an audio file needs Tracker Pro.

## Your data

This plugin contains only written instructions for Claude. It runs no code, stores nothing and sends nothing anywhere.

The tools Claude uses come from Tracker's own Claude connector, which runs on your Mac and talks only to Tracker. What Claude reads from your song is sent to Anthropic as part of your Claude conversation, like anything else you share with Claude. Tracker asks before it lets Claude in. Privacy: https://editlab.app/editlab-tracker/privacy.html#claude
